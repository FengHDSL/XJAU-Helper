# XJAU-Helper 发布资产分支

本分支仅存放 [新农助手（XJAU-Helper）](https://github.com/FengHDSL/XJAU-Helper) 的安装包（HAP），
便于在 Release 之外提供直链下载；源码请见 `main` 分支。

| 版本 | 文件 | 说明 |
|------|------|------|
| v1.4.1 | [XJAU-Helper_v1.4.1.hap](./XJAU-Helper_v1.4.1.hap) | 2026-10-12 |

> 安装方式：将 .hap 传输到鸿蒙设备，使用「文件管理」打开安装；或在 PC 端通过 hdc 安装（`hdc install XJAU-Helper_v1.4.1.hap`）。
